# Журнал изменений

Все заметные изменения приложения MangaFlow. Формат — [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/),
версии — [SemVer](https://semver.org/lang/ru/). Релизы с APK: [GitHub Releases](https://github.com/KOTBCTAKAHE/mangaflow-app/releases).

Для обновлений, которым нужен сервер, указано, что поменять в бэкенде
([mangaflow-backend](https://github.com/KOTBCTAKAHE/mangaflow-backend/blob/main/CHANGELOG.md)).

## [3.2.0] — 2026-11-22

### Новое
- **Страница тайтла построена вокруг обложки.**
  - Обложка во всю ширину занимает верх страницы и медленно «дышит», то есть плавно приближается и смещается. Вверху она чёткая, а ниже растворяется в размытии и фоне страницы.
  - Поверх неё — крупная карточка обложки с мягким свечением её собственного цвета и бликом по краю, как у печатной обложки.
  - Название набрано крупно по центру, под ним авторы и плашки: статус с «живой» точкой у онгоингов, тип, число глав, возраст, источник.
  - При прокрутке шапка плавно уменьшается и уступает место названию в верхней панели.
- **Вся страница в цветах обложки.** Раньше от обложки брался только цвет кнопок. Теперь из её цвета собирается полная палитра Material You: фон, карточки, кнопки, прогресс и метки.
- **Тап по обложке открывает её на весь экран.** Обложка перелетает в просмотр, её можно приблизить щипком. Закрывается тапом или свайпом.
- Заглушка, пока тайтл загружается, повторяет новую раскладку страницы.

## [3.1.1] — 2026-11-21

### Изменено
- **Мини-обновление с любой версии начиная с 2.7.0.** Раньше мини-патчи собирались только с трёх последних версий, а со старых приходилось качать полный APK (около 57 МБ). Теперь патч к новой версии есть для каждой версии начиная с 2.7.0, и с 2.7.0 можно сразу обновиться до последней. Версии до 2.7.0 не умеют применять патчи, им по-прежнему предлагается полный APK. Для редкой универсальной сборки патчи есть только с трёх последних версий.

## [3.1.0] — 2026-11-21

### Новое
- **Живые превью в настройках.** Рядом с настройками чтения нарисованы маленькие телефоны, на которых видно, что изменится, ещё до включения:
  - **Режим чтения.** «Лента» прокручивается вниз, «Слева направо» и «Справа налево» листаются тапом с нужной стороны, «Разворот» показывает две страницы. В «Настройки → Чтение» режим по умолчанию теперь выбирается прямо по этим анимациям вместо списка в окне. Те же анимации стоят на карточках режимов в настройках читалки.
  - **По кадрам.** Камера переходит от кадра к кадру в порядке чтения манги, а остальная страница затемняется.
  - **Обрезать белые поля.** Появляется линия обреза, и страница увеличивается до содержимого.
  - **Зоны касания.** Подсвечиваются края («листать») и середина («меню») с отметкой тапа. Если зоны выключены, весь экран — меню.
  - **Один тайтл — все источники.** В список глав въезжают строки с других сайтов.

  Выключенная настройка показывает неподвижную картинку «как без неё». Если в системе отключены анимации, превью тоже не двигаются.

## [3.0.1] — 2026-11-21

### Исправлено
- Список «Найдено в N источниках» прятался за нижней панелью. Теперь он и все остальные нижние окна открываются поверх панели. Если источников много, список прокручивается.
- Поиск больше не склеивает основной тайтл с побочной историей. Например, «Человек-бензопила» и «Человек-бензопила: История Химено, Аки и Табака» снова разные результаты, и главы второго не попадут в общий список глав первого. Исправлено на сервере.

## [3.0.0] — 2026-11-21

### Главное: один тайтл — все источники
- **Поиск больше не дублирует тайтл.** Раньше один тайтл показывался столько раз, сколько сайтов его называли по‑разному: «Поднятие уровня в одиночку» на одном, «Solo Leveling» на другом. Теперь результаты объединяются ещё и по английским и оригинальным названиям, которые отдают сами сайты. Разные тайтлы с похожими названиями, например «…: Рагнарёк», остаются отдельными.
- **Общий список глав.** На странице тайтла появляются главы, которых нет на его сайте, но есть на других русских источниках. Рядом с такой главой подписан её сайт, а над списком написано, откуда что добавлено, например «Главы из 3 источников: +5 с ReManga». Сначала список открывается сразу, а через секунду‑две дополняется главами с других сайтов.
- **Если сайт лежит, глава откроется с другого.** Когда та же глава есть на нескольких сайтах, при ошибке приложение само берёт её с другого.
- **Новые главы — откуда угодно.** Уведомления и список обновлений учитывают главы, которые вышли на любом из источников, а не только на «своём». Старые главы с других сайтов не засыпят уведомлениями: при первой проверке они считаются уже известными.
- Прогресс, закладки, история и загрузки работают с главами с других сайтов как с обычными, всё хранится за тайтлом.
- Функцию можно выключить: «Настройки → Чтение → Один тайтл — все источники».

### Новое лицо
- **Главная.** Сверху «Продолжить чтение», под ней новая лента «Вышли новые главы»: обложки с номером главы, а непрочитанные отмечены цветом. Приветствие показывается, только пока продолжать нечего.
- **Поиск.** Одна строка на всё: если по названию ничего не нашлось, а запрос похож на описание (4 слова и больше), приложение само ищет по сюжету и пишет об этом.
- **Тайтл.** Главы идут сразу после описания, а описание свёрнуто до 3 строк. «Другие источники» и «Похожие» переехали под главы.
- **Читалка.** Панели управления сами прячутся через 2,5 секунды после открытия главы и снова показываются по тапу.
- **Настройки.** Вместо длинной стены 5 разделов: «Чтение», «Внешний вид», «Загрузки и контент», «Аккаунт и данные», «Подключение и приложение».

## [2.9.0] — 2026-11-21

### Новое
- **Дизайн Material You.**
  - На Android 12+ цвета приложения берутся из обоев телефона: кнопки, переключатели, панели и фон получают оттенок обоев.
  - В «Настройках → Внешний вид» появился цвет «Обои». Он включён у всех по умолчанию, и на любой из пяти прежних цветов можно вернуться в один тап. Прежние цвета теперь тоже окрашивают всё приложение, а не только кнопки.
  - Кнопки стали крупнее и с полностью скруглёнными краями, углы карточек и окон — мягче.
  - В нижней панели выбранная вкладка выделена «таблеткой».
  - Заголовки набраны новым шрифтом.
  - Карточка «Продолжить чтение» на главной стала заметно больше.
  - Вкладки сменяются с плавным переходом.
- **Обрезка белых полей.** В режиме страниц пустые края и номер страницы обрезаются, поэтому сама страница на экране крупнее. Поля определяются заранее для следующих страниц, так что при перелистывании ничего не прыгает. Обрезка включается в настройках читалки и в общих настройках. Страницы, где рисунок идёт до самых краёв, не трогаются.
- **Открыть свой файл.** В «Библиотеке» появилась кнопка «Открыть файл» (такая же есть в «Загрузках»). Подходят:
  - CBZ и ZIP;
  - PDF (страницы рисуются прямо на телефоне);
  - несколько картинок сразу — они становятся одной главой;
  - несколько файлов сразу — каждый файл становится главой одного тайтла, например тома `Berserk vol 01…`.

  PDF теперь можно открыть и из другого приложения через «Открыть в MangaFlow».

### Изменено
- «Коллекции» в библиотеке переименованы в «Полки».

## [2.8.2] — 2026-11-20

### Исправлено
- **Манхва и вебтуны в режиме страниц больше не сжимаются в узкую полоску.** Если страница больше чем в два раза выше своей ширины (кусок вертикальной ленты), она показывается во всю ширину экрана и прокручивается вниз пальцем. Касание края экрана или клавиша громкости сначала прокручивает её на экран, а когда страница кончилась, переходит к следующей. При возврате назад открывается конец предыдущей страницы. Свайп вбок листает страницы как обычно.
- Когда приложение видит такую ленту в режиме страниц, оно один раз предлагает переключиться на «Вертикальную ленту» кнопкой «Включить».

## [2.8.1] — 2026-11-20

### Изменено
- Функции, которые ещё дорабатываются, помечены значком «БЕТА». Это чтение по кадрам (в настройках, в меню и настройках читалки), поиск по скриншоту (в профиле и на экране поиска) и поиск по сюжету (переключатель «По сюжету» в поиске).

## [2.8.0] — 2026-11-20

### Добавлено
- **Прокси для подключения к серверу.** Раздел «Настройки → Подключение → Прокси» поддерживает HTTP и SOCKS5, в том числе с логином и паролем.
  - Ссылку вида `socks5://логин:пароль@адрес:порт` можно вставить из буфера.
  - Кнопка «Проверить подключение» показывает, отвечает ли сервер MangaFlow через прокси и за сколько миллисекунд.
  - По умолчанию через прокси идут только запросы к серверу MangaFlow. Переключатель «Весь трафик приложения» отправляет туда же картинки с сайтов-источников и загрузку обновлений.
  - Для SOCKS5 адреса сайтов определяет сам прокси, поэтому подмена DNS у провайдера не мешает.
  - Прокси работает и в фоне: при загрузке глав и при проверке новых глав.
  - Прокси хранится только на устройстве и не синхронизируется с аккаунтом. Устройства в локальной сети (передача по Wi‑Fi) всегда подключаются напрямую.

### Удалено
- **Нельзя указать свой сервер.** Приложение всегда работает с официальным сервером MangaFlow. Если раньше был указан другой адрес, после обновления приложение само вернётся на официальный. На экране входа вместо «Изменить сервер» теперь ссылка на настройку прокси.

## [2.7.2] — 2026-11-20

### Исправлено
- **«По кадрам» — новый распознаватель кадров.** На тестовом наборе из сотен страниц с известной разметкой он находит заметно больше кадров (75% против 58%) и реже ошибается (76% верных рамок против 60%). Страниц, разобранных целиком без единой ошибки, стало в 2,5 раза больше. Что изменилось:
  - Промежутком между кадрами считается только бумага самой страницы, то есть белое, которое соединяется с полями. Белое небо внутри кадра больше не разрезает кадр пополам.
  - Облачко, лежащее поверх промежутка, больше не склеивает соседние кадры.
  - Кадры без белого зазора, у которых общая рамка прервана облачком, теперь разделяются.
  - Ничего на странице не пропускается. Подписи и текст рядом с кадром показываются вместе с ним, а всё, что не попало ни в один кадр, становится отдельным кадром. Раньше в худших случаях терялась почти треть страницы, теперь не больше 10%.
  - Порядок чтения строится по рядам и колонкам на любой глубине. Высокий кадр сбоку читается до или после всей стопки кадров рядом с ним, а не посередине. Разворот из двух страниц читается сначала одна страница, потом другая.
- **Направление кадров не зависит от листания.** Японская манга читается справа налево, даже если страницы листаются слева направо. Манхва, маньхуа и комиксы читаются слева направо. В настройках читалки появился раздел «По кадрам»: включение режима и порядок кадров («Авто», «Справа налево», «Слева направо»).
- **Свайп по кадру переключает кадры.** Раньше свайп просто сдвигал увеличенную картинку, теперь он ведёт к следующему или предыдущему кадру, в ту же сторону, что и листание. Щипок по-прежнему увеличивает.
- **Переход назад на прошлую страницу открывает её последний кадр**, а не первый. Соседние страницы больше не путают, с какого кадра начинать.
- Иногда кадр показывался не сразу, а сначала открывалась вся страница. Теперь нужный кадр открывается сразу.

## [2.7.1] — 2026-11-20

### Исправлено
- **Чтение «По кадрам» переделано.**
  - Раньше кадры искались только по белым промежуткам через всю страницу, поэтому вместо отдельного кадра показывались целые ряды или полстраницы. Теперь распознаются и панели, разделённые одними чёрными рамками без белого зазора, высокие кадры через несколько рядов и кадры, где рисунок или облачко заходит на соседний.
  - Бумага кремового или серого цвета больше не мешает: цвет фона определяется по краям страницы.
  - Страница анализируется в большем разрешении (600 px вместо 360), чтобы тонкие промежутки между кадрами не пропадали.
  - Порядок чтения: ряды сверху вниз, в ряду — справа налево (для манги).
  - Всё вокруг текущего кадра затемняется, чтобы читать только его. Двойной тап по-прежнему показывает страницу целиком.

## [2.7.0] — 2026-11-20

### Добавлено
- **Обновления по воздуху мини-патчами.** Приложение больше не отправляет качать APK в браузере. Оно скачивает небольшой патч «ваша версия → новая», собирает из него новый APK прямо на телефоне и открывает установку. Обычно патч весит 2–6% от полного APK: например, 0,1–3 МБ вместо 59 МБ. Собранный APK сверяется с выпуском по SHA-256. Если патч не подошёл (APK ставили не из релизов GitHub или это слишком старая версия), приложение само скачает полную версию. При первом обновлении Android попросит разрешить MangaFlow установку приложений.
- Для каждого выпуска CI готовит патчи с трёх предыдущих версий для каждой сборки (arm64, armv7, universal) и файл `ota.json` с размерами и хэшами.

Мини-обновления начинают работать со следующей версии после 2.7.0: саму 2.7.0 нужно поставить как обычно.

## [2.6.1] — 2026-11-20

### Добавлено
- **Сохранение страницы в галерею.** Долгое нажатие на страницу в читалке открывает меню «Сохранить в галерею / Отправить»; тот же пункт есть в меню «⋮». Страница сохраняется в «Изображения/MangaFlow» с понятным именем (тайтл, глава, номер страницы). Если включено ИИ-улучшение, сохраняется улучшенная версия. На Android 10 и новее разрешения не нужны, на более старых приложение один раз спросит доступ к памяти.

## [2.6.0] — 2026-11-20

### Добавлено
- **Поиск по сюжету.** На экране поиска появился переключатель «По названию / По сюжету». Опишите, что помните, — «школьница переродилась пауком в подземелье», «самый слабый охотник качается в одиночку», — и сервер найдёт тайтл по описаниям во всех источниках. Понимает русский и английский, ключи не нужны. Если поиск по названию ничего не нашёл, а запрос похож на описание, приложение само предложит поиск по сюжету.
- **Лента «Для вас».** На главной вместо подборки по жанрам — настоящие рекомендации, полный список открывается по кнопке «Ещё»:
  - «Подобрано для вас» — тайтлы с похожим сюжетом на то, что вы читаете и любите;
  - «Потому что вы читали …» — к двум последним тайтлам;
  - «Читают вместе с вашими» — что читают люди с похожей библиотекой;
  - «Высоко оценили друзья» и «Популярно в MangaFlow на этой неделе».
  У каждой карточки подписано, почему она здесь. Тайтлы, которые уже есть в библиотеке, не предлагаются.
- **«Похожие» на странице тайтла** — по сюжету и по тому, что читают вместе с ним.
- **Вход по PIN, отпечатку или лицу.** «Настройки → Приватность → Вход по PIN»: PIN из 4–6 цифр (хранится только в виде хэша в защищённом хранилище телефона) и отпечаток или лицо, если они настроены. Блокировка сразу или через 1, 5 или 15 минут после выхода из приложения. После пяти неверных попыток — пауза. «Забыли PIN?» сбрасывает его через блокировку экрана телефона.
- **Инкогнито.** Пока включено, не сохраняются история, прогресс глав и поисковые запросы — и ничего не синхронизируется. Сверху на всех экранах видна пометка «Инкогнито», по нажатию её можно выключить.
- **Скрывать в недавних приложениях** — вместо страниц пустой экран при переключении приложений (на Android 13+ скриншоты при этом работают).
- **Виджет «Библиотека»** на рабочий стол: четыре тайтла (сначала с новыми главами, с отметкой «+N»), счётчик новых глав, нажатие открывает тайтл. Обновляется и после фоновой проверки новых глав. Оба виджета теперь можно добавить прямо из приложения: «Настройки → Виджеты на рабочий стол».

### Исправлено

### Сервер

## [2.4.2] — 2026-11-19

## [2.4.1] — 2026-11-19

### Улучшено
- **Поиск по скриншоту находит намного больше.** Картинку проверяют сразу два движка: SauceNAO (страницы манги) и trace.moe (кадры аниме — большинство роликов в ТикТоке нарезаны из аниме-адаптации; по нему находится манга, из которой сделано аниме). - Если ничего не нашлось, видно, что ответил каждый движок (нет ключа, лимит, нет совпадений).

### Сервер
- Нужен бэкенд от 2026-11-19 (`./update.sh`). trace.moe работает без ключа; для страниц манги по-прежнему нужен бесплатный `SAUCENAO_API_KEY`.

## [2.4.0] — 2026-11-19

### Добавлено
- **Чтение по кадрам.** В страничном режиме тап по краю плавно приближает следующий кадр (порядок справа налево для манги), двойной тап — вся страница. Включается в ⋮ читалки или в Настройках.

- **Друзья.** Добавление по нику, лента «кто что читает и как оценил», профиль друга, советы тайтлов («Посоветовать другу» на странице тайтла).

- **Комментарии к главам** (⋮ → «Комментарии к главе»): лайки, привязка к странице, удаление своих.
- **Читать вместе.** Комната с кодом: страницы листаются у всех синхронно, реакции-эмодзи и короткие сообщения; можно читать в своём темпе.
- **Трекеры Shikimori, MyAnimeList, AniList.** Прочитанные главы и оценки отправляются автоматически; тайтл находится по названию, можно выбрать вручную.
- **Импорт из Mihon / Tachiyomi** (`.tachibk`): библиотека, категории → коллекции, прочитанные главы.
- **Автоскачивание новых глав** для тайтлов «Читаю»: до 5 глав вперёд, только по Wi-Fi и на зарядке.
- **Экономия трафика на мобильном:** страницы в 720px, чёткость возвращает улучшение ИИ на телефоне.

### Сервер
- Нужен бэкенд 2026-11-19 или новее (`./update.sh`). Для поиска по скриншоту — `SAUCENAO_API_KEY`, для трекеров — OAuth-ключи сервисов в `.env`.
