# MangaFlow

Читалка манги, манхвы и маньхуа с русскоязычными источниками на Flutter. Основная платформа — Android, сборка под iOS тоже предусмотрена.

Backend (FastAPI, источники, синхронизация): **[KOTBCTAKAHE/mangaflow-backend](https://github.com/KOTBCTAKAHE/mangaflow-backend)**.

## Возможности

- **Главная:** «Продолжить чтение», популярное, последние обновления, недавно добавленное, рекомендации по жанрам вашей библиотеки. Источник переключается одним касанием.
- **Поиск:** глобальный по всем источникам одновременно, с debounce и отменой предыдущего запроса. Дубликаты из разных источников склеиваются, видно, откуда каждый результат. Есть фильтры (тип, статус, сортировка), жанры можно включать и исключать, есть история запросов и каталог каждого источника с его собственными фильтрами.
- **Библиотека:** вкладки «Избранное», «Читаю», «Планирую», «Завершено», «Отложено», «Брошено», пользовательские коллекции, сортировка, поиск, бейджи новых глав.
- **Страница тайтла:** обложка, альтернативные названия, описание, жанры, автор, художник, статус, источник. Кнопки «Читать» / «Продолжить», «В библиотеку», «В избранное». Список глав с сортировкой, отметками прочитанного, массовым выделением и загрузками.
- **Читалка:**
  - режимы: вертикальная лента (бесконечная, с переходом в следующую главу), страницы LTR, RTL и разворот из двух страниц; режим запоминается для каждого тайтла;
  - предзагрузка следующих страниц, масштаб щипком и двойным тапом, панорамирование;
  - зоны касания для листания; интерфейс скрывается тапом, в режиме immersive остаётся только «12 / 40»;
  - ползунок для перехода к странице, переключение глав, автопереход к следующей главе;
  - яркость внутри приложения, три фона, экран не гаснет;
  - битые страницы можно перезагрузить кнопкой «Повторить»;
  - прогресс сразу пишется в SQLite (с debounce 400 мс и при сворачивании), поэтому переживает аварийное закрытие.
- **Офлайн:** загрузка глав в очередь с продолжением после перезапуска (уже скачанные страницы пропускаются). Открытые тайтлы кэшируются, библиотека, история, прогресс и настройки хранятся локально.
- **Аккаунт (необязателен):** регистрация и вход по JWT с ротацией refresh-токенов. Библиотека, коллекции, прогресс, история и настройки синхронизируются между устройствами (offline-first, last-write-wins). При первом входе гостевые данные загружаются в аккаунт.
- **Ещё:** уведомления о новых главах (фоновая проверка WorkManager), статистика (главы, время, серии, календарь активности), экспорт и импорт бэкапа в формате, совместимом с сервером, отключение источников, исключение жанров, качество изображений.

## Архитектура

```
lib/
├── app/            # MaterialApp, роутер (go_router), жизненный цикл/синхронизация
├── core/           # тема и дизайн-токены, сеть (Dio + refresh), SQLite, провайдеры Riverpod
├── data/
│   ├── models/     # доменные модели
│   ├── remote/     # API-клиенты backend
│   ├── local/      # DAO поверх sqflite
│   ├── repositories/  # каталог (с офлайн-фолбэком), библиотека, чтение, auth, настройки
│   └── services/   # загрузки, sync engine, бэкапы, уведомления, фоновые задачи
├── features/       # экраны: home, discover, library, title, reader, profile
└── widgets/        # компоненты дизайн-системы
```

UI не обращается к сети и БД напрямую: экраны → провайдеры → репозитории/сервисы → DAO/API. Подробнее в [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md), дизайн-система описана в [docs/DESIGN_SYSTEM.md](docs/DESIGN_SYSTEM.md).

## Сборка Android APK

Готовые APK собираются в GitHub Actions при каждом push: **Actions → CI → артефакт `mangaflow-apk`**.

Локальная сборка:

```bash
# Flutter stable (проверено на 3.50), JDK 17, Android SDK
flutter create --org com.mangaflow --project-name mangaflow --platforms android,ios .   # создаёт только недостающие файлы
python3 tool/patch_android.py      # разрешения, cleartext, иконки, desugaring
flutter pub get
flutter test
flutter build apk --release --dart-define=API_BASE_URL=https://ваш-сервер
```

APK лежит в `build/app/outputs/flutter-apk/`. Для публикации в магазин нужна своя подпись (`android/key.properties`, см. документацию Flutter); по умолчанию release подписывается debug-ключом.

**Адрес сервера** задаётся при сборке через `--dart-define=API_BASE_URL=…` (по умолчанию `http://10.0.2.2:8080` — это хост-машина из Android-эмулятора) и меняется прямо в приложении: *Профиль → Настройки → Адрес backend*.

### Быстрая проверка на эмуляторе

```bash
# терминал 1 — backend
git clone https://github.com/KOTBCTAKAHE/mangaflow-backend && cd mangaflow-backend/infrastructure
cp .env.example .env && docker compose up -d --build
# терминал 2 — приложение
flutter run
```

## Тесты

```bash
flutter test
```

Покрыты статистика и серии, зоны касания читалки, форматирование, сериализация моделей, разбор ошибок API, DAO на in-memory SQLite (LWW-слияние, монотонность прогресса, офлайн-кэш тайтлов, коллекции, лента обновлений) и виджеты.

## Источники и ограничения

Каталоги берутся через backend, который переносит парсеры из [redcatpet/mangayomi-ru-sources](https://github.com/redcatpet/mangayomi-ru-sources) (Apache-2.0). Многие сайты ограничивают доступ не из России; состояние каждого источника видно в разделе *Профиль → Источники*. Приложение не обходит авторизацию и платный доступ на сайтах.

Шрифт Manrope распространяется по SIL Open Font License (`assets/fonts/Manrope-OFL.txt`).
